# 水縁市 ふるさと住民パス

ふるさと住民登録後の「来訪・活動・購買・トークン保有」をつなぐ、架空自治体向けの実証提案モックです。

## コンセプト

国のふるさと住民登録制度を置き換えず、登録後の関係深化を担う民間連携レイヤーとして設計しています。

- 応援スコア: 来訪・参加・担い手活動を蓄積する、消費しない活動マイレージ
- 限定FiNANCiEポイント: 商品購入・有料体験の購入者本人へ還元
- コミュニティトークン: 限定ポイントと交換し、保有または返却。支払いには使用しない
- プレミアム登録: 購入額やトークン保有数ではなく、自治体指定の活動実績で判定

トップでは残高やスコアを見せず、地域ニュース、利用できる特典、今日からできる関わりを優先します。トークン、生涯ポイント、限定ポイント、売上金はマイページに集約しています。

トークンの交換・返却ではチャートを表示せず、選択時点の条件と変動可能性を提示してから、もう一度ボタンを押して確定する二段階操作にしています。

## 起動

```bash
python3 -m http.server 5190
```

`http://localhost:5190/` を開いてください。

## 注記

水縁市、事業者、数値、制度接続、トークン条件はすべて提案・実証検討用のサンプルです。実導入時は最新の制度ガイドライン、FiNANCiEの仕様、法務・会計・個人情報保護要件を確認してください。
