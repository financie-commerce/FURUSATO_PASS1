# 水縁市 ふるさと住民パス

HISとFiNANCiEによる「第2のふるさとプロジェクト」の展開を想定し、ふるさと住民登録後の「来訪・活動・購買・トークン保有」をつなぐ、架空自治体向けの実証提案モックです。

設計意図、競合優位性、役割分担、実証KPI、地域横展開の考え方は [`PROPOSAL_SUPPLEMENT.md`](./PROPOSAL_SUPPLEMENT.md) に整理しています。

## コンセプト

国のふるさと住民登録制度を置き換えず、登録後の関係深化を担う民間連携レイヤーとして設計しています。

モデル事業案は500人・20事業者・6か月を想定し、対象活動参加100人、90日再関与率30%を主要な検証目標とします。継続判断では参加単価だけでなく、自治体職員の事務時間と参加事業者の継続意向も確認します。

- 応援スコア: 来訪・参加・担い手活動を蓄積する、消費しない活動マイレージ
- 限定FiNANCiEポイント: 商品購入・有料体験の購入者本人へ還元
- コミュニティトークン: 限定ポイントと交換し、保有または返却。支払いには使用しない
- プレミアム登録: 購入額やトークン保有数ではなく、自治体指定の活動実績で判定

活動実績は、イベント来訪では現地QR、担い手活動では主催者承認を想定します。申込時点では加算せず、参加確認後に生涯ポイントとプレミアム判定へ反映します。

限定ポイント・コマース・トークンは任意の民間拡張です。基本実証は、登録、情報発信、活動募集、参加確認、生涯ポイント、称号、官民サポートのみでも実施できます。

トップでは残高やスコアを見せず、地域ニュース、利用できる特典、今日からできる関わりを優先します。トークン、生涯ポイント、限定ポイントはマイページに集約しています。

右上のベルから、交換・返却・ポイント獲得などの「あなたへの通知」と、自治体の活動報告である「水縁市から」を分けて確認できます。

生涯ポイントは消費しない活動記録として称号へつながります。称号特典はクーポンや日常優待などの常設・ライトな内容、トークン保有特典は先行案内や企画参加などの限定・特別な体験に役割を分けています。

トークンの交換・返却ではチャートを表示せず、選択時点の条件と変動可能性を提示してから、もう一度ボタンを押して確定する二段階操作にしています。返却後の売上金確認・出金申請は自治体パスに持たせず、FiNANCiEプラットフォームへ引き継ぎます。

返却しても生涯ポイントと活動履歴は残ります。一方、現在の保有数から算出する保有ステージと特典は変動します。返却確認時に前後の保有数・ステージ・利用できなくなる特典を具体的に表示します。

## 起動

```bash
python3 -m http.server 5190
```

`http://localhost:5190/` を開いてください。

## 注記

水縁市、事業者、数値、制度接続、トークン条件はすべて提案・実証検討用のサンプルです。実導入時は最新の制度ガイドライン、FiNANCiEの仕様、法務・会計・個人情報保護要件を確認してください。
